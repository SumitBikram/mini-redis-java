# Concept notes

One note per concept, written **after** building it and breaking it. A note's job is to make
the concept explainable from memory: in an interview, in a code review, or six months from now.

**How to add one:** copy [`TEMPLATE.md`](TEMPLATE.md) to `kebab-case-name.md`, fill in every section
(especially *Break it*), and add a row below in the same PR.

Rule of thumb: if the *Break it* section is empty, the note isn't finished.
